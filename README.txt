JARVIS Android v0.1 (source, abhi compile nahi kiya gaya)
1. Android Studio (laptop) mein ye folder kholein, Build > Build APK.
2. APK phone mein install karein (Unknown sources allow karna padega).
3. App kholein, mic ki ijazat dein.
4. Phone control ke liye: Settings > Accessibility > JARVIS > ON.
